# 花蓮高中課表查詢系統

依班級或教師查詢每週課表的靜態網頁，資料來源為「115學年度第1學期班級手排課」Excel 匯出檔，並依教師課表 PDF（115-1教師課表(正式)）校正過教師編號與部分課程內容。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 課表查詢網頁本體（原檔名 `hlhs_schedule.html`，部署到 GitHub Pages 時改名為 `index.html`，讓網站根目錄網址就能直接開啟），資料已內嵌其中，**可直接雙擊用瀏覽器開啟**。右上角有「分機座位查詢 →」連結可切換到分機座位子網頁 |
| `hlhs_schedule_data.json` | 課表查詢資料庫（JSON 格式），包含班級、教師、教室、課表明細、分組/跑班選修對照表 |
| `directory.html` | 處室分機暨教師座位查詢子網頁，資料已內嵌其中，**可直接雙擊用瀏覽器開啟**；需與 `index.html` 放在同一層目錄，兩邊互相有連結可以切換 |
| `hlhs_directory_data.json` | 分機座位資料庫（JSON 格式），欄位為建築物／樓層／處室別／姓名／分機／座位分區 |

部署到 GitHub Pages 時，`index.html` 與 `directory.html` 兩個檔案都要放在網站根目錄（資料都已內嵌在各自檔案裡）；兩份 `*_data.json` 是給想直接讀取原始資料、自行串接其他系統時使用的。

## 功能

- **依班級查詢**：依年級分組選擇班級代碼，顯示該班完整每週課表，並標示導師姓名。
- **依教師查詢**：搜尋教師姓名或代碼，顯示該師完整每週課表（含協同教學、跑班選修、行政會議/科務研究會）。
- **班級 ↔ 教師互相跳轉**：點選課表中任一堂課的教師姓名，直接跳轉查看該教師課表；點選教師課表中的班級名稱，直接跳轉查看該班課表。
- **分組 / 選修班別對照**：頁面最下方以色塊列出需要跨班/分組上課的課程（高一本土語、高二數學分組、高三數學乙分組、高三理組生物跑班、高二跨班選修），列出對應教師與教室。
- 支援手機與桌機瀏覽，並自動偵測系統淺色/深色主題。
- **分機座位查詢**（`directory.html`）：依建築物／樓層瀏覽各處室人員分機，和平樓（西側/東側）、忠孝樓的教師研究室另有座位圖視覺呈現；也可依班級查詢導師分機與座位，並跳轉查看該導師實際座位圖。

## 資料版本與已知限制

- 課表資料以 115 學年度第 1 學期（2026-09-07 匯出）為準，如學校公告調課，請以教務處正式公告為準。
- 教師編號已對照「115-1教師課表(正式).pdf」校正（原始試算表有 6 位教師編號為暫代碼，已更新為正式編號）。
- 「204~209 班・高二跨班選修」因屬學生個人自由選課，教師課表僅能列出完整開課清單（課程/教師/教室），**無法標示實際是哪個學生／哪個班選了哪一堂**；教師課表會將 204~209 六班同時列出供參考，非精確分班結果。
- 若日後學校釋出更完整的選課對應名單，可據此補上更精確的班級歸屬。

## 如何更新資料

這份網頁是用一套可重複使用的流程（Claude Code 技能 `school-schedule-query-site`）產生的，重新產生的做法：

1. 準備新學期的「班級手排課」Excel 匯出檔。
2. 視需要更新三個設定檔（用來修正試算表缺漏、記錄跑班/分組課程、增加選修對照表）。
3. 執行 `build_json.py` 產生 `hlhs_schedule_data.json`。
4. 執行 `package.py` 產生課表網頁（自動包含正確的手機版 viewport 設定），部署前記得把檔名改成 `index.html`。

技能與詳細操作說明存放在本機 `C:\Users\user\.claude\skills\school-schedule-query-site\`，請 Claude 依此技能操作即可，不需要每次重新從零說明需求。
